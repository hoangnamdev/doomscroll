# Doomscroll

A lightweight, browser-based scroll experiment exploring infinite interactions and simple event-driven mechanics. 

Built and deployed as a rapid prototype to test client-side rendering behaviors on the web.

---

### 🎮 Live Demo
Test the build in your browser:  
👉 **[doomscroll-ochre.vercel.app](https://doomscroll-ochre.vercel.app)**

---

### Architecture & Tech Stack

- **Markup & Layout:** Semantic HTML5, CSS3
- **Client Logic:** Vanilla JavaScript (`logic.js`)
- **Hosting & CI/CD:** Vercel
